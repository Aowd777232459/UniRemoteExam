# تقرير التحقق والاختبار v6

## تحقق ثابت تم داخل الحزمة

- لا توجد أسرار SMTP أو مفاتيح API أو Connection String خاص بجهاز المطور.
- لا توجد مجلدات `bin`, `obj`, `.vs` في نسخة التسليم.
- جميع نماذج POST تحتوي Anti-forgery، إضافة إلى فلتر حماية عام.
- كلمات مرور بيانات العرض مخزنة بصيغة ASP.NET Identity V3 ومطابقة لكلمة `Demo@12345`.
- جداول v6 وحقول النتيجة والمقررات متطابقة مع نماذج Entity Framework.
- سكربت التثبيت لا يحذف قاعدة قائمة، وسكربت المسح منفصل وموسوم بوضوح.

## اختبارات تشغيل يجب تنفيذها على جهاز التسليم

| رقم | الحالة | المتوقع |
|---:|---|---|
| 1 | تسجيل الدخول بالحساب التجريبي | إجبار تغيير كلمة المرور ثم فتح لوحة الدور |
| 2 | خمس كلمات مرور خاطئة | قفل الحساب 15 دقيقة |
| 3 | إنشاء مقرر وتسجيل طالب | ظهور المقرر والطالب في صفحة الإدارة |
| 4 | طالب غير مسجل يفتح رابط اختبار | رفض الوصول من السيرفر |
| 5 | إرسال اختبار بلا نموذج إجابة كامل | رفض طلب النشر |
| 6 | محاولة تعديل اختبار قيد المراجعة | رفض التعديل |
| 7 | بدء الاختبار من نافذتين | بقاء محاولة نشطة واحدة |
| 8 | اختيار Choice تابع لسؤال آخر | رفض الطلب |
| 9 | انتهاء وقت السؤال | قفل الإجابة من السيرفر |
| 10 | انتهاء مدة الاختبار | تسليم تلقائي وتسجيل AutoSubmitted |
| 11 | درجة مقالية أكبر من الحد | رفض الحفظ |
| 12 | اعتماد قبل تصحيح كل المقاليات | رفض الاعتماد |
| 13 | اعتماد مكتمل | تخزين النتيجة والنسبة والحالة والمصحح |
| 14 | خاصية ShowCorrectAnswers مفعلة | ظهور صفحة المراجعة للطالب بعد الاعتماد |
| 15 | SMTP غير مضبوط | اعتماد النتيجة وتسجيل البريد Skipped |
| 16 | تصدير CSV | ظهور العربية صحيحة في Excel بترميز UTF-8 BOM |

## تنبيه التحقق

بيئة إعداد الحزمة لا تحتوي على .NET SDK أو SQL Server؛ لذلك لم ينفذ `dotnet build` أو اختبار قاعدة حي داخلها. شغّل `VERIFY_V6.ps1` والاختبارات أعلاه على جهاز المناقشة، وسجل النتيجة الفعلية وصورة الإثبات.
