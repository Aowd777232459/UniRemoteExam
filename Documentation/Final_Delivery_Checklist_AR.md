# قائمة التسليم النهائي

- [ ] تشغيل `dotnet restore` و`dotnet build -c Release` دون أخطاء.
- [ ] تنفيذ قاعدة جديدة ثم تسجيل الدخول بكل الأدوار.
- [ ] تنفيذ ترقية v5 على نسخة احتياطية تجريبية.
- [ ] تنفيذ سيناريو: إنشاء مقرر ← اختبار ← مراجعة ← أداء ← تصحيح ← نتيجة.
- [ ] ضبط SMTP أو توضيح أنه غير مفعل في العرض.
- [ ] التقاط صور v6 ووضعها في `Documentation/Screenshots`.
- [ ] تحديث الوثيقة الأكاديمية بمخططات `Documentation/Diagrams`.
- [ ] عدم تضمين بيانات طلاب حقيقية أو كلمات مرور إنتاج.
- [ ] الاحتفاظ بنسخة احتياطية من قاعدة العرض.
- [ ] تجربة العرض على نفس جهاز وشبكة المناقشة.
