# سجل تغييرات الإصدار v7

- استعادة المصدر الكامل بدل الأرشيف الناقص.
- تحديث حزم EF Core إلى 10.0.10 وتفعيل NuGet Audit.
- إضافة Rate Limiting لتسجيل الدخول.
- إضافة Retry وSplit Query لاتصال SQL Server.
- إضافة دعم Reverse Proxy وCookie آمن للإنتاج.
- إضافة فحص صحة الخادم وقاعدة البيانات عبر `/health`.
- إضافة PWA وواجهة واضحة عند انقطاع الشبكة دون تخزين صفحات حساسة.
- إضافة تطبيق .NET MAUI لأندرويد وويندوز.
- إضافة برنامج تثبيت Windows وAPK موقع عبر GitHub Actions.
- إضافة Dockerfile وحزمة نشر خادم آلية.
- إضافة وثائق الشبكة والمزامنة والبناء والتوقيع.
