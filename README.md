# UniRemoteExam v6 Final

> تحديث v7: أضيفت تطبيقات أندرويد وويندوز، المزامنة المركزية، فحص الشبكة، وبناء GitHub الآلي. راجع `Documentation/CHANGELOG_v7_AR.md`.

نظام جامعي لإدارة الاختبارات الإلكترونية عن بُعد بأربعة أدوار: المدير، الدكتور، الطالب، والكنترول.

## أهم إصلاحات الإصدار v6

- إضافة الأقسام والفصول الأكاديمية والمقررات وتسجيل الطلاب.
- حصر اختبارات الطالب في المقررات المسجل فيها والتحقق من الصلاحية داخل السيرفر.
- استبدال منطق «أعمال السنة المشتقة» بدرجة اختبار فعلية محفوظة ومعتمدة.
- تخزين الدرجة الآلية والمقالية والنهائية والنسبة وحالة النجاح والمصحح وتاريخ الاعتماد.
- إضافة مدة كلية للاختبار وتسليم تلقائي من جهة السيرفر عند انتهاء الوقت.
- منع محاولتين نشطتين ومنع تكرار إجابة السؤال أو درجة السؤال المقالي.
- منع تعديل الاختبار بعد طلب المراجعة أو النشر أو بدء أي محاولة.
- حماية جميع عمليات POST برمز Anti-forgery والتحقق من حدود الدرجات.
- تطبيق صفحة مراجعة الإجابات الصحيحة عند تفعيل الدكتور للخاصية.
- توحيد سياسة الزمن: التخزين UTC والعرض/الإدخال بتوقيت صنعاء.
- كلمات مرور مشفرة، تغيير إلزامي عند أول دخول، وقفل مؤقت بعد محاولات دخول فاشلة.
- إزالة الأسرار وملفات البناء وإضافة إعدادات نموذجية وملفات تثبيت/ترقية آمنة.

## متطلبات التشغيل

- Windows 10/11 أو خادم Windows/Linux مناسب.
- .NET 10 SDK.
- SQL Server 2019 أو أحدث، أو LocalDB للتجربة المحلية.
- Visual Studio 2026 أو محرر يدعم ASP.NET Core.

## تطبيق أندرويد وتطبيق ويندوز والمزامنة

- أضيف مشروع `.NET MAUI` داخل `Apps/UniRemoteExam.Client` يستهدف أندرويد وويندوز من مصدر واحد.
- يطلب التطبيق رابط الخادم الآمن عند أول تشغيل، ثم يستخدم الخادم وقاعدة البيانات المركزيين نفسيهما على كل الأجهزة.
- المزامنة فورية عبر الشبكة؛ لا توجد قواعد بيانات منفصلة على الجوال والكمبيوتر.
- يدعم الموقع أيضًا التثبيت المباشر كتطبيق PWA من المتصفح.
- تنتج إجراءات GitHub ملف APK موقعًا وبرنامج تثبيت Windows وحزمة نشر الخادم.

راجع:

- `Documentation/Network_Deployment_AR.md`
- `Documentation/Build_Android_Windows_AR.md`

## التثبيت الجديد

1. افتح `Database/CREATE_DATABASE_FULL.sql` في SQL Server Management Studio.
2. نفّذ الملف مرة واحدة؛ سينشئ قاعدة `UniRemoteExamDb_Final` دون حذف قاعدة موجودة.
3. راجع `appsettings.json` أو انسخ `appsettings.example.json` واضبط الاتصال.
4. من مجلد المشروع نفّذ:

```powershell
dotnet restore
dotnet build
dotnet run
```

## ترقية قاعدة v5

1. أنشئ نسخة احتياطية كاملة من قاعدة البيانات.
2. نفّذ `Database/04_Upgrade_From_v5.sql` على قاعدة `UniRemoteExamDb_Final`.
3. لا تنفذ ملف إعادة الضبط على بيانات حقيقية.
4. شغّل المشروع واختبر سيناريوهات `Documentation/Test_Report_AR.md`.
